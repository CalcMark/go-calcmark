<task type="auto">
  <name>Task 2: Create GoReleaser configuration</name>
  <files>.goreleaser.yaml</files>
  <action>
Create `.goreleaser.yaml` at project root with GoReleaser v2 configuration:

```yaml
version: 2

project_name: calcmark

before:
  hooks:
    - go mod tidy

builds:
  - id: cm
    main: ./cmd/calcmark
    binary: cm
    env:
      - CGO_ENABLED=0
    goos:
      - darwin
      - linux
      - windows
    goarch:
      - amd64
      - arm64
      - arm
    goarm:
      - "6"
    ignore:
      - goos: darwin
        goarch: arm
      - goos: windows
        goarch: arm
    ldflags:
      - -s -w
      - -X main.Version={{.Version}}
      - -X main.BuildTime={{.Date}}

archives:
  - id: default
    format: tar.gz
    format_overrides:
      - goos: windows
        format: zip
    name_template: >-
      {{ .ProjectName }}_
      {{- .Version }}_
      {{- .Os }}_
      {{- .Arch }}
      {{- if .Arm }}v{{ .Arm }}{{ end }}
    files:
      - none*

checksum:
  name_template: 'checksums.txt'
  algorithm: sha256

changelog:
  sort: asc
  filters:
    exclude:
      - '^docs:'
      - '^test:'
      - '^chore:'
      - Merge pull request
      - Merge branch

brews:
  - name: calcmark
    repository:
      owner: CalcMark
      name: homebrew-tap
      branch: main
      token: "{{ .Env.HOMEBREW_TAP_GITHUB_TOKEN }}"
    folder: Formula
    homepage: "https://github.com/CalcMark/go-calcmark"
    description: "CalcMark - calculations embedded in markdown"
    license: "MIT"
    install: |
      bin.install "cm"
    test: |
      system "#{bin}/cm", "version"

release:
  github:
    owner: CalcMark
    name: go-calcmark
  draft: false
  prerelease: auto
```

Key decisions per CONTEXT.md and RESEARCH.md:
- Version tag format: `v` prefix (Go ecosystem standard)
- Archive format: tar.gz for macOS/Linux, zip for Windows
- Checksum: Single checksums.txt with SHA256
- No GPG signatures (keep it simple)
- 7 binaries: macOS (amd64, arm64), Linux (amd64, arm64, arm), Windows (amd64, arm64)
- Binary only in archives (no LICENSE, README per CONTEXT.md)

<task type="auto">
  <name>Task 3: Update GitHub Actions release workflow</name>
  <files>.github/workflows/release.yml</files>
  <action>
Replace the existing release.yml with GoReleaser-based workflow:

```yaml
name: Release

on:
  push:
    tags:
      - 'v*.*.*'

permissions:
  contents: write

jobs:
  release:
    name: Build and Release
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version-file: 'go.mod'

      - name: Run GoReleaser
        uses: goreleaser/goreleaser-action@v6
        with:
          distribution: goreleaser
          version: "~> v2"
          args: release --clean
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          HOMEBREW_TAP_GITHUB_TOKEN: ${{ secrets.HOMEBREW_TAP_GITHUB_TOKEN }}
```

Key changes from old workflow:
- Removed gh CLI installation step (not needed)
- Removed release.sh execution (replaced by GoReleaser action)
- Added GoReleaser action with v2 version
- Added HOMEBREW_TAP_GITHUB_TOKEN for tap push (will need to be created by user)
- Kept fetch-depth: 0 (already correct)
- Kept go-version-file: 'go.mod' (already correct)
  </action>
