  <name>Task 2: Investigate and fix convert_rate math or display</name>

  <action>
Based on test results from Task 1, identify the root cause.

**If calculation bug (rate_functions.go):**
The math at line 83-84 is:
```go
ratio := sourceSeconds.Div(targetSeconds)  // 1 / 3600 = 0.000278
newAmount := rate.Amount.Value.Div(ratio)  // 10 / 0.000278 = 36000
```

Wait - this looks WRONG. To convert from per-second to per-hour:
- 10 things per 1 second = 10 * 3600 things per 3600 seconds = 36000/hour
- Should be: newAmount = rate.Amount.Value.Mul(ratio) not Div

Check if the ratio calculation is inverted. The comment says:
> "Example: Converting 1000/second to per hour → multiply by ratio"

But the code does Div(ratio). This is likely the bug!

**Fix approach:**
```go
// Converting from sourceSeconds to targetSeconds:
// - per second to per hour: multiply by 3600 (there are 3600 seconds in an hour)
// - per hour to per second: divide by 3600
conversionFactor := targetSeconds.Div(sourceSeconds)
newAmount := rate.Amount.Value.Mul(conversionFactor)
```

**If display bug (display.go):**
Check FormatRate to see if it's misformatting the Rate type.

Run test after fix:
