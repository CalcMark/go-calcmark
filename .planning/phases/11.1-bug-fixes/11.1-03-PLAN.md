Modify ComputeAlignedModel() to filter TextBlock content in preview pane.

Current behavior (lines 280-304): TextBlocks render markdown for preview.

New behavior: For TextBlocks, only show:
1. Headings (lines starting with #)
2. Empty lines (for vertical spacing)

Filter approach in CASE 2 and CASE 3a (around line 288):
```go
} else if !isCalcBlock && textBlockPreviewCache != nil {
    // CASE 2: TextBlock - filter to show only headings
    for blockLineIdx, lineResult := range blockResults {
        lineText := lineResult.Source
        trimmed := strings.TrimSpace(lineText)

        // Only show headings in preview (lines starting with #)
        if strings.HasPrefix(trimmed, "#") {
            // Keep heading content from cache
            wrappedPreviewLines = textBlockPreviewCache[blockLineIdx]
        } else {
            // Non-heading TextBlock content -> blank in preview
            wrappedPreviewLines = []string{""}
        }
    }
}
```

This preserves vertical alignment (blank lines for non-heading content) while filtering out blockquotes, links, paragraphs, etc.
