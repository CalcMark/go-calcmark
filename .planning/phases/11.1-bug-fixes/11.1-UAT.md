### Test 1: DELETE Key Removes Last Character

**Plan:** 11.1-01

**Scenario:**
1. Run `./cm` (or build with `task build` first)
2. Type a single character: `a`
3. Press Left arrow to move cursor before the character
4. Press DELETE key

**Expected:**
- The character `a` should be deleted
- The line should be empty
- No crash or unexpected behavior

**Status:** pending

### Test 2: DELETE Key After Line Join

**Plan:** 11.1-01

**Scenario:**
1. Run `./cm`
2. Type `hello` then press Enter
3. Type `world`
4. Press Up arrow then End to go to end of first line
5. Press DELETE to join the lines (first line becomes `helloworld`)
6. Press DELETE again (should delete `w`)

**Expected:**
- After first DELETE: `helloworld` on one line
- After second DELETE: `helloorld` (the `w` is deleted)
- Cursor stays in correct position

**Status:** pending

### Test 3: convert_rate Displays Correct Result

**Plan:** 11.1-02

**Scenario:**
1. Run `./cm`
2. Type: `convert_rate(10 mb/s, per hour)`

**Expected:**
- The preview pane should show approximately `35.2 GB/h` or `36000 MB/h`
- The result should NOT show `35999.99...` or any truncated decimal
- The calculation should be exact (10 MB/s * 3600 seconds = 36000 MB/h)

**Status:** pending

### Test 4: Preview Pane Filters Blockquotes

**Plan:** 11.1-03

**Scenario:**
1. Run `./cm`
2. Type the following (press Enter between lines):
   ```
   x = 10
   > This is a blockquote
   y = 20
   ```

**Expected:**
- Preview pane shows:
  - `x -> 10` (aligned with first line)
  - Blank line (aligned with blockquote)
  - `y -> 20` (aligned with third line)
- The blockquote text "> This is a blockquote" should NOT appear in the preview pane

**Status:** pending

---

### Test 5: Preview Pane Preserves Headings

**Plan:** 11.1-03
