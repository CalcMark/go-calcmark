  <name>Task 2: Implement boundary triggers</name>
  <files>cmd/calcmark/tui/editor/undo.go</files>
  <action>
Add boundary control methods to UndoManager:

1. CommitCurrentBatch() - Commit current operations as a batch immediately
   - Only commits if current has operations
   - Clears current after commit
   - Sets timestamp to time.Now()

2. ForceBoundary() - Create boundary without waiting for timer
   - Same as CommitCurrentBatch but with explicit name for semantic clarity
   - Used by Enter, navigation, line joins

3. Add documentation comments explaining when boundaries are created:
   - Timer expiry (1 second pause) -> auto boundary
   - Enter key -> immediate boundary (per CONTEXT.md: always)
   - Arrow keys -> immediate boundary (per CONTEXT.md discretion: yes for navigation)
   - Line joins (Delete at EOL, Backspace at BOL) -> immediate boundary (per CONTEXT.md: separate step)
   - Paste -> immediate boundary before AND after (one step per CONTEXT.md)
   - Scroll -> NO boundary (per CONTEXT.md discretion: no for scroll)

4. Boundary logic summary:
   - Character typing: No boundary (grouped by timer)
   - Delete/Backspace within line: No boundary (grouped by timer)
   - Everything else: Immediate boundary
