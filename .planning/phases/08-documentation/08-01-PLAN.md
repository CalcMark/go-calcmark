```tape
# hero.tape - CalcMark demo GIF
Output docs/images/hero.gif

Require cm

Set Shell "bash"
Set FontSize 18
Set Width 900
Set Height 450
Set Theme "Catppuccin Mocha"
Set Padding 15
Set TypingSpeed 60ms
Set Framerate 12

# Start with empty file
Type "cm demo.cm"
Enter
Sleep 1500ms

# Type a simple budget calculation
Type "income = $5000"
Enter
Sleep 400ms
Type "rent = $1500"
Enter
Sleep 400ms
Type "savings = income * 0.20"
Enter
Sleep 400ms
Type "remaining = income - rent - savings"
Enter
Sleep 1s

# Let user see final state
Sleep 2s
```

Run VHS to generate GIF:
```bash
cd /Users/bitsbyme/projects/go-calcmark
vhs docs/images/hero.tape
```

Note: VHS may not work with interactive TUI apps. If VHS fails to capture TUI properly, use `vhs record` for manual capture or create checkpoint for user to record.

Target: GIF under 2MB, ~10-15 seconds.
