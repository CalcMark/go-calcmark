  <name>Task 1: Create command_menu.go with command infrastructure</name>
  <files>cmd/calcmark/tui/editor/command_menu.go</files>
  <action>
Create new file `cmd/calcmark/tui/editor/command_menu.go` with:

1. **Command struct** defining each command:
```go
type Command struct {
    Name        string // Display name: "Save", "Export", "Quit"
    Accelerator string // Key hint: "Ctrl+S", "Ctrl+E"
    Description string // Brief description
    Category    string // "file", "edit", "view", "help"
}
```

2. **EditorCommands slice** containing all commands organized by category:
   - File: Save (Ctrl+S), Export (Ctrl+E), Quit (Ctrl+Q)
   - Edit: Undo (Ctrl+Z), Redo (Ctrl+Y)
   - View: Toggle Preview (Ctrl+P)
   - Navigation: Word Left (Ctrl+Left/Alt+B), Word Right (Ctrl+Right/Alt+F), Doc Start (Ctrl+Home), Doc End (Ctrl+End)
   - Help: Full Help (F1)

3. **CommandMenuState struct** to track menu state:
```go
type CommandMenuState struct {
    Selected int // Currently selected command index
}
```

4. **handleCommandMenuKey function** with signature `func (m Model) handleCommandMenuKey(msg tea.KeyMsg) (tea.Model, tea.Cmd)`:
   - Up arrow: decrement Selected (clamp to 0)
   - Down arrow: increment Selected (clamp to len-1)
   - Enter: execute selected command, return to StateDefault
   - Escape: return to StateDefault without executing
   - Continue typing dismisses menu (like autocomplete)

Note: Commands are informational - accelerators still execute directly. The menu is for discovery, not the primary action path.
  </action>
