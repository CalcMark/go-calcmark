## Summary

Replaced the minimal text-input save dialog with a visual file browser using `charmbracelet/bubbles/filepicker`. Users can now browse directories and type filenames in a standard Save As dialog pattern.

## What Was Built

### Files Modified

1. **cmd/calcmark/tui/editor/filepicker.go**
   - `FilePickerFocus` type with `FocusFileBrowser` and `FocusFilename` modes
   - `initFilePicker()` creates configured filepicker with dark theme styling
   - `DirAllowed = false` so Enter on directory navigates (not selects)
   - `addExtensionIfMissing()` ensures .cm extension

2. **cmd/calcmark/tui/editor/model.go**
   - Added `StateFilePicker` to InputState enum
   - Added `filePicker`, `filePickerFocus`, `newFileName` fields to Model
   - `handleFilePickerKey()` handles Tab focus switching, typing, and navigation
   - Modified `Update()` to route async directory-read messages to filepicker
   - Modified Ctrl+S to open file picker for new files

3. **cmd/calcmark/tui/editor/view.go**
   - `renderFilePickerOverlay()` renders full-screen modal with:
     - Directory header showing current path
     - File browser (dimmed when filename has focus)
     - Filename input field (always visible)
     - Contextual hints

### UX Design (Modified from Original Plan)

Original plan used 'n' key to enter filename mode. User feedback requested standard Save As dialog behavior:

- **Tab** switches focus between browser and filename input
- Both sections always visible (inactive one dimmed)
- Filename input starts with focus for quick naming
- Standard keyboard navigation (arrows, Enter, Esc)

### Key Implementation Details

- Filepicker.Init() returns a command that triggers async directory reading
- Modified Update() to pass non-KeyMsg messages to filepicker when StateFilePicker active
- `DirAllowed = false` ensures Enter navigates into directories instead of selecting them

## Deviations from Plan

1. **Tab-based focus switching** replaced 'n' key mode switching per user request
2. **Both panels always visible** instead of mode-switching between them
3. **Focus indication via dimming** for clear visual feedback
4. **FilePickerFocus enum** replaced FilePickerMode (semantic clarity)
