<objective>
Remove architecture violation: spec/document importing impl/interpreter

Purpose: Enforce the core architecture rule that "spec can NEVER depend on impl". The spec/ directory
defines what CalcMark IS (the language specification). The impl/ directory defines how it runs
(the interpreter). Currently spec/document/evaluate.go and document.go import impl/interpreter,
which violates this boundary.

Output: Clean spec/document package with no impl/ imports. Document struct will be pure data
(no interpreter state). All execution logic remains in impl/document/evaluator.go.
</objective>
