# Phase 9.1 Plan 01: Remove impl/ Imports from spec/document Summary

Removed architecture violation where spec/document imported impl/interpreter. The spec/ directory defines what CalcMark IS (language specification) and should NEVER depend on impl/ which defines how it runs (interpreter).

## One-liner

EnvironmentWriter interface decouples spec/document from impl/interpreter; evaluate.go deleted.
