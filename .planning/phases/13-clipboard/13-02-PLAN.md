<task type="auto">
  <name>Task 1: Add selection highlighting style and view rendering</name>
  <files>cmd/calcmark/tui/editor/view.go</files>
  <action>
Modify the source pane rendering to highlight selected text:

1. Add a selection style constant (use lipgloss):
```go
selectionStyle := lipgloss.NewStyle().
    Background(lipgloss.Color("240")).  // Gray background
    Foreground(lipgloss.Color("255"))   // White text
```
Place this in the View() function or as a package-level var.

2. Create a helper method `(m Model) renderLineWithSelection(lineNum int, lineText string) string`:
   - If no selection (!m.HasSelection()), return lineText unchanged
   - Get selection range with m.GetSelectionRange()
   - If lineNum is outside selection range, return lineText unchanged
   - For lines within selection:
     - Calculate selectStart and selectEnd for this line
     - If lineNum == startLine: selectStart = startCol
     - If lineNum == endLine: selectEnd = endCol
     - If lineNum is a middle line: select entire line (0 to len)
     - Split line into 3 parts: before, selected, after
     - Apply selectionStyle to selected part
     - Return joined parts

3. Integrate into `renderSourcePaneAligned()`:
   - Find where line content is rendered (look for where editBuf or line text is output)
   - Wrap the line text through renderLineWithSelection before applying other styles
   - Be careful: editBuf is used for the current line being edited - apply selection there too

IMPORTANT: Use runeSlice() and runeLen() for UTF-8 safe slicing. The selection columns are rune positions, not byte positions.
  </action>
  <verify>Run `go build ./cmd/calcmark/...` - compiles without errors</verify>
  <done>Selection highlighting renders in view when selection exists</done>
</task>

<task type="auto">
  <name>Task 2: Add Ctrl+A handler and clear selection on navigation/typing</name>
  <files>cmd/calcmark/tui/editor/model.go</files>
  <action>
1. **Add Ctrl+A handler** in the key handling section (near other Ctrl+ handlers):
```go
case tea.KeyCtrlA:
    m.SelectAll()
    return m, nil
```
This calls the SelectAll() method from selection.go which sets anchor to 0,0 and cursor to end.

2. **Clear selection on navigation** - Add m.ClearSelection() at the start of:
   - handleArrowUp()
   - handleArrowDown()
   - handleArrowLeft()
   - handleArrowRight()
   - moveWordLeft() / moveWordRight()
   - moveCursorToLineStart() / moveCursorToLineEnd()
   - moveCursorToDocumentStart() / moveCursorToDocumentEnd()
   - handleHomeKey() / handleEndKey()

   Pattern: Add `m.ClearSelection()` as the FIRST line of each handler.

3. **Clear selection on typing** - Add m.ClearSelection() in:
   - handleRuneInput() - BEFORE inserting the character
   - handleBackspaceKey() - BEFORE deleting
   - handleDeleteKey() - BEFORE deleting
   - handleEnterKey() - BEFORE line split

   If there's a selection when typing, the typical behavior is to DELETE the selection first, then insert. For simplicity in this phase, just clear selection (Phase 13 focuses on copy/cut/paste, not "type to replace selection").

4. **Note on Shift+Arrow**: The research mentions Shift+Arrow for extending selection. This is not in the requirements (only Ctrl+A for select-all). Skip this for now - it can be added later if needed.
  </action>
