   - Anchor on earlier line
   - Anchor on later line

5. **GetSelectedText() string** - Returns the selected text as a string. For multi-line selection, join lines with "\n". Use existing m.doc.GetLines() to get document lines. Handle:
   - Same-line selection: substring from startCol to endCol

6. **DeleteSelection() string** - Deletes the selected text from the document, returns deleted text. MUST:
   - Call recordEdit() for undo support (per decision [12-03])
   - Handle multi-line deletion by joining first and last lines
   - Clear selection after deletion
   - Return deleted text for clipboard operations
   - Use existing runeSlice/runeLen helpers for UTF-8 safety

7. **SelectAll()** - Sets anchor to 0,0 and moves cursor to end of last line

Use existing helpers: runeSlice(), runeLen() for UTF-8 safe string operations.

Reference existing patterns:
- Check m.doc.GetLines() usage in model.go for accessing lines
- Check handleBackspaceKey for line joining pattern
- Check recordEdit() for undo recording pattern
