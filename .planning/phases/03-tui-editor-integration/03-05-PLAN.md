<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete interactive editor with:
- Cursor movement (arrows, Home/End, Ctrl+Arrow word movement)
- Viewport scrolling with margin
- Debounced live evaluation (~100ms)
- Dependent variable updates
- Single unified Model (ModelV2 deleted)
- Dirty state tracking and save prompt on quit
  </what-built>
  <how-to-verify>
1. Build and run the editor:
   ```bash
   task build
   ./cm edit testdata/example.cm
   ```
   (Or create a new test file)

2. Test cursor movement:
   - Arrow keys: Do they move by logical line (not visual line in wrapped text)?
   - Home/End: Do they go to start/end of logical line?
   - Ctrl+Left/Right: Do they move by word?
   - Left at column 0: Does it wrap to previous line?
   - Right at end: Does it wrap to next line?

3. Test scrolling:
   - Open a long document (or create one with 30+ lines)
   - Navigate to bottom: Does viewport scroll smoothly?
   - Navigate to top: Does viewport scroll back?
   - Is cursor always visible with some margin?

4. Test live evaluation:
   - Type "= 2 + 2" on a new line
   - Does "4" appear in the results pane within ~200ms?
   - Type "x = 10" then "= x * 2"
   - Does the second line show "20"?
   - Change "x = 10" to "x = 20"
   - Does the dependent line update to "40"?

5. Test save behavior:
   - Make a change (type something)
   - Press Ctrl+Q to quit
   - Do you see the save prompt "Unsaved changes! Save before quit? (y/n/c)"?
   - Press 'c' to cancel and continue editing

6. Overall feel:
   - Does the editor feel responsive?
   - Is typing smooth with no visible lag?
   - Do results update quickly without flicker?
  </how-to-verify>
  <resume-signal>
Type "approved" if all checks pass.
If issues found, describe them and they will be addressed in gap closure.
  </resume-signal>
</task>
