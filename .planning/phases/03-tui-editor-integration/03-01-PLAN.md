<task type="auto">
  <name>Task 1: Add Ctrl+Arrow word movement handlers</name>
  <files>cmd/calcmark/tui/editor/model.go</files>
  <action>
Add two new handler functions for word-based cursor movement:

1. `handleCtrlLeftKey()` - Move cursor left to previous word boundary
   - If at column 0, move to end of previous line first (like handleLeftKey)
   - Skip whitespace backwards, then skip word characters backwards
   - Word boundaries are: whitespace (unicode.IsSpace) and punctuation (unicode.IsPunct)
   - Stop at column 0 or word boundary

2. `handleCtrlRightKey()` - Move cursor right to next word boundary
   - If at end of line, move to start of next line first (like handleRightKey)
   - Skip current word characters forward, then skip whitespace forward
   - Stop at end of line or word boundary

Add case handlers in handleDefaultKey for tea.KeyCtrlLeft and tea.KeyCtrlRight.

Use unicode package (already imported transitively via the spec) for IsSpace/IsPunct checks.

Reference existing handleLeftKey/handleRightKey for the line-wrapping behavior.

AVOID: Do not try to be CalcMark expression-aware. Use standard word boundaries only.
  </action>
  <verify>
Run `go build ./cmd/calcmark/...` to confirm compilation.
Run `go test ./cmd/calcmark/tui/editor/... -run TestEditor` to confirm no regressions.
  </verify>
  <done>
handleCtrlLeftKey and handleCtrlRightKey functions exist and are wired into handleDefaultKey.
Word movement uses unicode.IsSpace and unicode.IsPunct for boundaries.
  </done>
</task>
